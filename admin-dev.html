How schedules work

A template is the master schedule a lot is stamped from. When you add a lot, it takes a frozen copy of the template — editing the template later never changes lots already building.

Phases group tasks into weeks of construction. Tasks carry duration, lag, predecessors and a critical-path flag. Critical tasks drive the completion date and the active phase; non-critical tasks have float and don't.

Stage map ties stage codes (0.3–9.5) to the tasks that trigger them — finish the trigger tasks, the stage advances automatically.

🔓 Gates are optional. A gate is an extra hold you can layer on top of the schedule — the utility gates (gas, power, water) are the example in use today. When a gate is unconfirmed, the lot's reported stage is capped (at 5.9) even though its true stage has advanced. This surfaces houses that are physically built past a point but can't be reported there yet. A template works fine with no gates at all — only add them when you need that extra hold.

Cloning copies everything — phases, tasks, gates, stage map — into an independent new template. Fastest way to make a Basement or Townhome variant of an existing schedule, then edit the differences.
